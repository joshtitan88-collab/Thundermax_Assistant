ThunderMax Tuning Expanded Guide (~50 Pages)
Introduction
This expanded guide is a comprehensive reference for ThunderMax tuning. It combines information
from official manuals with custom strategies, step-by-step procedures, and advanced tuning insights.

Installation & Setup
- Remove stock ECM, install ThunderMax ECM. - Replace narrow-band O2 sensors with wide-band O2
sensors. - Use dielectric grease on all connectors. - If catalyst-equipped exhaust, weld in 18mm bungs
for sensors. - After installation, perform ECM initialization: 1. Ignition ON (20s) 2. Ignition OFF (5s) 3.
Start engine, idle 15s.

Base Map Selection
Selecting the correct base map is critical. Key elements include: - Engine size (cubic inches) - Throttle
body & injector size - Camshaft profile - Exhaust system type Choose the closest map available. Once
written to ECM, clear diagnostic codes and Learned Fuel Adjustments before first startup.

Air-Fuel Ratio (AFR) Strategy
AFR tuning is the foundation of performance, rideability, and reliability. Typical targets: - Idle & low
cruise: 13.6–13.8 AFR for smooth idle & throttle response. - Mid torque band: 13.2–13.4 AFR to
eliminate sogginess in roll-ons. - Heavy load / roll-on: 12.9–13.0 AFR for strong torque, safe
combustion. - Wide open throttle (WOT): 12.8 AFR for power and piston cooling. - Decel (0–2% TPS,
1500–2800 RPM): 13.2–13.4 AFR with Decel Enrichment ~60 to prevent popping.

Ignition Timing Strategy
Ignition tables must balance power, throttle crispness, and knock prevention. Rules of Thumb: - Idle:
768–1280 RPM should be stable, typically 16–18°. - Light throttle cruise: Timing increases gradually
with RPM for efficiency. - Midrange torque band: Rear jug typically runs 1–2° retarded vs. front to
prevent echo knock. - WOT: Maintain safe advance; reduce only if ping occurs. Ping Corrections: Light ping: Retard 1–2°. - Moderate ping: Retard 3°. - Heavy ping: Retard 5°. - Severe ping: Retard
7–8°.

AutoTune Management
AutoTune learns VE corrections during riding. Best practices: - Start with 1500–4000 RPM tuning
range. - Avoid letting AutoTune overwrite idle or decel zones excessively. - Lock down stable AFR
zones (e.g., idle, WOT) to prevent drift. - Save sessions and review correction heat maps before writing
permanently.

Troubleshooting Common Issues
1. Decel popping: - Check Decel Fuel Cut (disable if needed). - Set Decel Post Fuel Enrichment
~50–60. - Verify AFR in 0–2% TPS zone. 2. Idle hunting / echo exhaust: - Ensure idle AFR ~13.6–13.8.
- Set rear jug −1.5° timing offset in 1500–2800 RPM / 4–10% TPS. 3. Bike dies after flash: - Re-check
base map compatibility. - Clear learned fuel adjustments before testing. - Verify O2 sensor health. 4.
Soggy midrange: - Richen AFR to 13.2 in 2300–3200 RPM / 10–25% TPS. - Verify ignition not overly
retarded.

Advanced Strategies
- Rear Cylinder Thermal Tuning: Retard 1–2° timing in 2200–2800 RPM to reduce knock/echo. Multi-Mode Profiles: Create Street (13.6 AFR cruise), Race (leaner cruise, aggressive timing), and Heat
(richer + retarded timing above 230°F) modes. - Fuel Phase Smoothing: Blend VE maps to reduce
harsh transitions. - AutoTune Control: Use selective disable to prevent drift in already-correct zones.
