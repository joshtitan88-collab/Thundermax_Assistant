                 Universal Tuner Prompt Framework

This document provides a fast-track set of prompts to accelerate AI understanding of different
motorcycle tuning systems (e.g., ThunderMax, Dynojet Power Vision 1). Use these prompts in
sequence to establish context, workflow, and troubleshooting logic quickly.



Prompt 1: System Overview
I need you to become an expert in the Dynojet +Power Vision 1 (PV1)+ Touchscreen Tuning Module.
Review and master all available PV1 documentation, including installation, firmware, C3 software,
AutoTune, logging, map editing, and advanced features. Build the same level of deep technical
understanding you have with ThunderMax.



Prompt 2: My Bike Setup
My bike is a 2023 Harley Low Rider ST with a 131ci motor. I’m switching to +Power Vision 1+. Here are
my mods [list them]. Help me establish a base tune strategy using PV1’s maps, AFR tables, spark
tables, and AutoTune logic.



Prompt 3: Feature Parallels
Compare the PV1 features to ThunderMax equivalents. Show me how AFR tables, VE learning, and
spark advance are handled differently in PV1. Make me a cross-reference sheet.



Prompt 4: Workflow Build
Walk me through the step-by-step workflow to create, test, and refine a PV1 tune. Include base map
selection, logging, AutoTune, table editing, flashing, and review.



Prompt 5: Deep Dive Tables
Give me a detailed breakdown of each PV1 editable table (AFR, timing, VE, fuel offset, idle control,
etc.), what it controls, what safe ranges are, and how to tune them for power, reliability, and heat
management.



Prompt 6: Problem → Fix Logic
If my AFR log shows lean spikes at low RPM/high load, what should I adjust in PV1? Give me the exact
table, cells, and direction to move values.



Prompt 7: Race vs Street Profiles
Help me build 3 complete PV1 tune profiles (Race, Street, Heat Management) using the same structure
we did for ThunderMax.
