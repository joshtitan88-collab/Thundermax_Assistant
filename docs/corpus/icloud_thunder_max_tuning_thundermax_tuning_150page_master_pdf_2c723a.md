ThunderMax Tuning – Master Handbook (150 Pages)
Introduction
This handbook consolidates ThunderMax documentation with advanced strategies, AFR/timing maps,
AutoTune management, and troubleshooting.

Installation & Setup
- Install ECM - Replace narrow-band O2 with wide-band O2 - Initialize ECM (ON 20s, OFF 5s, idle 15s)
- Clear codes & LFAs after flashing

Base Map Selection
Match engine size, throttle body, cam, and exhaust. Flash closest base map, then clear LFAs before
riding.

AFR Strategies
Idle/Cruise: 13.6–13.8 Torque Band: 13.2–13.4 Heavy Roll-On: 12.9–13.0 WOT: 12.8 Decel: 13.2–13.4
with enrichment ~60

Ignition Timing
Idle: 16–18° @ 768–1280 RPM Mid Torque: Retard rear jug 1–2° WOT: Hold if no ping Ping fix: -1° to
-8° depending on severity

AutoTune Management
Run 1500–4000 RPM range first Lock idle/WOT zones Review correction maps before writing Disable
AutoTune in stable areas

Troubleshooting
Decel pop → disable fuel cut, add enrichment Idle echo → retard rear jug timing Bike dies → check
map + clear LFAs Soggy midrange → richen to 13.2, verify spark

Advanced Tuning
Rear jug timing offsets, fuel phase smoothing, VE blending, and 3-mode profiles (Street, Race, Heat).
