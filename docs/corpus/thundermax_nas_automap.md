                        Using the AutoMap Feature

The AutoMap feature uses the ‘Learned Fuel Adjustments’ made in your fueling pages by the
AutoTune module to re-write the map and incorporate anticipated changes to the fueling curves.

The TMax Control Center in the Software can be helpful in determining whether or not running the
‘AutoMap’ feature is necessary.




   1. Link to your module

   2. Go to Map Editing>AutoMap (Write “Learned Fuel Adjustments (CLP
