How to Initialize a Thunder Max Module- (all versions)

   Turn key to ‘ON’ position for 30 seconds.

   Turn key to ‘OFF’ position for 30 seconds.

   Repeat key on / off 30 seconds, process 3 times.

   Upon completion of the Key Cycle, Turn key to ‘ON’ position and
    start engine.

   Allow engine to run until it reaches normal operating temperature.



It is VERY important that when performing this cycle, the key remains
in the ‘ON’ and ‘OFF’ position for a full 30 Seconds.

If after completing the Key Cycle the bike is running poorly,
immediately shut engine off for one minute and repeat the process
from the beginning.
