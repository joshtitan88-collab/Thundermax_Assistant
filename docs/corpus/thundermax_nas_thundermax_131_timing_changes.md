ThunderMax 131 Tune – Timing Adjustments

Throttle Roll-On Belly Zone (Main Timing Adjustment)
•   Target Range: 2000–3200 rpm, 20–60% TPS.
•   Retard ignition timing –2° to –3° across this band.
•   This prevents ping under heavy load roll-ons (the 'belly' of the curve).
•   If ping remains after test ride, remove an additional –1° at the exact rpm/TPS where ping occurs.



Idle & Low RPM Stability
•   Set 768, 1024, and 1280 rpm timing all to the same value (recommended ~18°).
•   This prevents 'idle hunt' caused by timing fluctuations.
•   Smoothly increase timing as RPM rises above idle (e.g., 1536 @ 22°, 1792 @ 25°, 2048 @ 30°, etc.).



Timing vs Engine Temperature
•   226–240°F: Retard –1°
•   241–260°F: Retard –2°
•   261–280°F: Retard –3° to –4°
•   This prevents ping/knock when engine is heat-soaked in traffic.



Rear Cylinder Trim
•   If rear cylinder runs 15–20°F hotter than front, apply –1° timing in the same belly band (2000–3200 rpm, 20–60%
    TPS).
•   This balances combustion temperatures and smooths operation.



Validation Test Loop
•   Warm engine to ~230°F.
•   Perform 3rd gear roll-ons from 2000→3500 rpm at 30–60% TPS.
•   Listen for ping; if present, pull an extra –1° at that specific cell.
•   Check full-throttle: if ping only appears at WOT, reduce WOT cells –1° to –2° instead of belly cells.
•   Cruise steady at 2500–3000 rpm (≤15% TPS): ensure no surging. Adjust fuel if necessary (AFR ~14.2).
