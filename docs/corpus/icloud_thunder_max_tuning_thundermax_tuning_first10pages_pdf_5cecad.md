AutoTune Management
1. Start tuning in the 1500–4000 RPM band. 2. Lock stable regions (idle, decel, WOT) so AutoTune
doesn’t rewrite them. 3. Allow corrections in cruise and torque bands only. 4. After each session: save,
review VE heatmap, then write if consistent. 5. Disable AutoTune in finished zones to prevent
over-learning.
